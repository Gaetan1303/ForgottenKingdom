# Cartes de Veyr

Les cartes définitives seront produites par le pipeline ComfyUI du projet.

Noms attendus par le runtime :

- `veyr_world.png` — carte générale de Veyr, 16:9 recommandé, sans texte incrusté si possible.
- `marches_cendrees.png` — zoom sur les Marches Libres / zone de départ.

En leur absence, `MapView` affiche un fond procédural et les marqueurs restent utilisables.
